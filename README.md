# Eurosatory 2026 — Deux expériences / Two experiences

Projets de la série **#100AIExperiments** par **Riana Terter** — réalisés avec Claude Fable.
Two self-contained web experiences built for the Eurosatory 2026 defence exhibition (June 15–19, Paris-Nord Villepinte).

## Contenu / Contents

| Fichier | Description |
|---|---|
| `index.html` | Page d'accueil reliant les deux expériences / Landing hub |
| `plan-de-vol.html` | **Plan de vol** — guide visiteur interactif : programme officiel des conférences du ministère des Armées (horaires, salles, intervenants), carte tactique du site, agenda personnalisable, infos pratiques. Bilingue FR/EN. |
| `ciel-clair.html` | **Ciel clair** — jeu d'interception anti-drones : 5 niveaux, difficulté croissante, avions civils à protéger, score partageable. Bilingue FR/EN. |

Chaque fichier est autonome (HTML/CSS/JS, images embarquées) — aucun build, aucune dépendance.
Each file is fully self-contained — no build step, no dependencies.

## Publier avec GitHub Pages / Publish with GitHub Pages

1. Repository → **Settings** → **Pages**
2. Source : **Deploy from a branch** → branche `main`, dossier `/ (root)` → **Save**
3. Le site est en ligne sous `https://<votre-utilisateur>.github.io/<nom-du-repo>/`
   - Guide : `…/plan-de-vol.html` · Jeu : `…/ciel-clair.html`
